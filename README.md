# Varikode AI Platform

## Project Overview

Varikode AI Platform is an AI chatbot SaaS project designed to provide a dashboard for managing AI assistants and related chatbot functionality.

I am currently working on **Milestone 1: Application Setup and Dashboard** and **Milestone 2: Authentication**.

## Milestone 1: Application Setup and Dashboard

### Work Done So Far

- Set up the React application using Vite.
- Organized the frontend project structure.
- Created the main application components and CSS files.
- Worked on the dashboard interface and its styling.
- Added components for assistant settings, chat history, and the chat widget.

### Key Files

| File | Purpose |
|---|---|
| `dashboard/src/App.jsx` | Main application component |
| `dashboard/src/App.css` | Main application styling |
| `dashboard/src/theme.css` | Theme styling |
| `dashboard/src/AssistantSettings.jsx` | Assistant settings interface |
| `dashboard/src/ChatWidget.jsx` | Chat widget interface |
| `dashboard/src/ChatHistory.jsx` | Chat history interface |
